# 🤖 Telegram AI Bot with OpenAI Integration

A feature-rich Telegram bot that integrates with OpenAI's API to provide intelligent conversations in Telegram.

## ✨ Features

- **AI Conversations**: Natural language conversations using OpenAI's GPT models
- **Multiple Models**: Support for GPT-4, GPT-4 Turbo, and GPT-3.5 Turbo
- **Customizable Settings**: Adjustable temperature and max tokens per user
- **Conversation History**: Maintains conversation context across messages
- **User Sessions**: Persistent sessions for each user
- **Admin Controls**: Admin-only commands for bot management
- **Inline Keyboards**: Interactive settings and model selection
- **Error Handling**: Comprehensive error handling and logging
