## 1. Secure Tier Encryption (Admin-Blind Messages)

**Status: Shipped**

Implemented double-envelope AES-256-GCM encryption for message content at rest. This is the cornerstone of our enterprise security tier — even platform admins cannot read customer message content.

- **Architecture**: Per-org Tenant Master Key (TMK) wrapped by `MESSAGE_ROOT_KEY`, per-workspace Data Encryption Key (DEK) wrapped by TMK.
- **Canonical AAD binding** (`aad_v1`): org/workspace/message/role/timestamp/key_version — prevents ciphertext transplant attacks.
- **Graceful degradation**: Decryption failure returns `[Encrypted message unavailable]` placeholder; crypto fields stripped from API/WebSocket responses via `Message.safe_dump()`.
- **Admin endpoints**: `POST /api/admin/organizations/{org_id}/enable-secure|disable-secure`, `GET .../encryption-status`.
- **Auto-backfill**: Enabling encryption automatically encrypts all existing messages in the org.
- **Audit trail**: Redis stream `encryption:audit` logs all key operations.
- **GPT-5.4 security audit**: Three rounds of fixes applied to `kms_service.py` based on automated security analysis — input validation, error handling, and key rotation hardening.

**Files**: `api/services/message_crypto.py`, `api/services/kms_service.py`, `api/routes/encryption.py`

## 2. AiOS-Style Mobile Dashboard

**Status: Shipped**

Complete rebuild of the mobile experience into an iOS-inspired home screen with swipeable pages, customizable widgets, and Aceternity-style theming.

### Core Features
- **Swipeable pages**: Touch/mouse-drag gesture navigation between Home, Widgets, and Agentic Conversations pages with page dots indicator.
- **App grid**: 6 app icons (Workspaces, Playground, Agents, Knowledge, Providers, Encryption) with drag-to-reorder (jiggle mode).
- **Widget system**: 6 widget types (Conversations, Usage, Knowledge, API Keys, Providers, Encryption) — all rendering live data. Users can show/hide widgets and reorder them; layout persists to Redis (`user_settings:{user_id}` → `aios_layout`).
- **Agentic Conversations**: Renamed from "Recent Conversations", now displays up to 7 items.

### Visual Design
- **Aceternity theme**: Aurora background animations, `ace-card` / `ace-glow-border` / `ace-shimmer` / `ace-text-shimmer` CSS classes applied throughout.
- **Screen edge glow**: Pulsing cyan→violet→pink gradient border on all `/m/` pages using `border-image` with keyframe animation.
- **Branded header**: Logo with cyan drop-shadow glow, "Ai" bold + "Assist" shimmer text, animated "SECURE" label between gradient dividers, date/time subtitle.
- **Branded loading screen**: Replaced generic spinner with full AiAssist SECURE branding — logo, shimmer text, and decorative lines — matching the dashboard header exactly.

### Quick Compose FAB
- **Floating action button**: Available on every mobile page (except Playground itself). Displays the AiAssist logo with holographic cyan/violet glow.
- **Bottom sheet**: Slides up with provider picker (grid layout), scrollable model selector with context window info, and "Launch Session" button.
- **Error handling**: 402 paywall detection, network error display, empty provider/model states.
- **Flow**: Tap FAB → pick provider → pick model → Launch → creates session via `POST /api/playground/sessions` → navigates to `/m/playground`.

### Mobile Playground
- **New route**: `/m/playground` — full playground experience adapted for mobile.
- **Aceternity-styled**: Dark cyan/violet theme, aurora background, screen glow, shimmer title.
- **Cloned from**: `OraclePlayground.tsx` with complete theme replacement.

### Auto-Detection
- `useMobileRedirect()` hook: Detects mobile UA/screen width and auto-redirects desktop routes to `/m/` equivalents.

**Files**: `MobileDashboard.tsx`, `MobileLayout.tsx`, `MobilePlayground.tsx`, `App.tsx`
