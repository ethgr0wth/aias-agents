## Design Notes for Image Generation

- All icons sit on a near-black field (`#0A0A0B`)
- Each icon is a rounded square (`16px radius`) with a diagonal gradient fill (`135deg`)
- The Lucide icon glyph sits centered in white at roughly 50% of the container size
- 12 icons per page in a 4×3 grid with ~16px gutters
- The overall aesthetic is dark glass with luminous gradient surfaces — think Bloomberg terminal meets iOS springboard
