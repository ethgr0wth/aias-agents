## Description

**AiAssist Secure** is a production-ready AI chat platform built for agencies, SaaS founders, and enterprises who've outgrown simple AI wrappers. Connect 11+ AI providers with your own API keys, deploy human-in-the-loop approval workflows, and build AI-powered apps — all from one self-hosted platform you fully control.

### Why AiAssist Secure?

You've tried the $39 scripts with monthly add-ons. You've paid per-seat SaaS fees that eat into your margins. You've cobbled together APIs and prayed they'd work together.

**AiAssist Secure is what comes next.**

- **Bring Your Own Keys (BYOK)** — Use your existing API keys from OpenAI, Anthropic, Google, Groq, Mistral, xAI, Cohere, DeepSeek, Perplexity, Together AI, and Fireworks. Switch providers without code changes.

## Key Features

### 11 AI Providers + P2P Network
Connect OpenAI, Anthropic (Claude), Google Gemini, Groq, Mistral, xAI (Grok), Cohere, DeepSeek, Perplexity, Together AI, and Fireworks AI. Plus access the PIN decentralized inference network for local LLMs.

### Shadow Mode (Enterprise HITL)
AI generates draft responses. Managers review and approve before delivery. Real-time WebSocket updates. Audit trail included. Perfect for regulated industries and high-stakes client communication.

### Keystone App Builder
Embedded development environment for building AI-powered applications. Surgical code editing prevents AI from truncating your code. Template system for rapid deployment.

### Multi-Tenant Architecture
Role hierarchy: Client → Reseller → Manager → Super Admin. Organization-level resource sharing. Workspace isolation. API key management per user or organization.

### Stripe Subscriptions Built-In
Four subscription tiers (Free, Basic, Pro, Enterprise) with Stripe integration. Webhook handling, grace periods, and lifecycle management included.

### Conversation Memory
Two-lane memory system with short-term buffer and session persistence. Configurable memory scopes. PII filtering. Context-aware responses across conversations.

### 4 Premium Themes
Malachi, Athena, Yvette, and Patriot themes with dark/light modes. 3D particle backgrounds. Smooth Framer Motion animations. Professional UI out of the box.

### Professional PHP Installer
18-step guided installation wizard. License verification. Redis & PostgreSQL configuration. No command-line expertise required.
