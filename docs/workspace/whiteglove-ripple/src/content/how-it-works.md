# How it works

From user behavior to personalized experience in milliseconds.

## Step 1: Capture
WhiteGlove watches how users interact — scrolls, clicks, hovers, time spent. All events are tracked passively without impacting performance.

## Step 2: Analyze
Events are batched and sent to AiAS for LLM-powered intent inference. The AI understands context and user goals.

## Step 3: Adapt
AI returns safe mutations — CSS changes, content swaps, section reordering. Changes are validated before applying.

## Step 4: Delight
The page smoothly transforms to match what the visitor is looking for. Transitions are seamless and natural.

---

The entire cycle happens in under 200ms, creating a truly responsive experience.
