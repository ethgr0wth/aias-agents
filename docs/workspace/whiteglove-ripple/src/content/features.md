# Everything you need for adaptive UX

WhiteGlove handles the complexity so you can focus on content and design.

## Event Tracking
Automatically captures scroll, click, hover, dwell time, and exit intent signals.

## AI Intent Engine
LLM-powered analysis infers what users want based on their behavior patterns.

## Dynamic Mutations
Safe, constrained CSS and content changes that adapt without breaking layouts.

## Command Bar
Natural language navigation. Users tell your site what they want to see. Press ⌘K or / to open.

## Markdown Content
Define content variants in markdown. Non-technical updates, zero deploys.

## BYOK Security
Bring your own LLM key via AiAS. Your data stays under your control.
