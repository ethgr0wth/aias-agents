# Voice Lab

Experiment with voice control and see how WhiteGlove responds to natural language.

## Getting Started

1. Click the microphone button in the bottom left
2. Say **"Hey WhiteGlove"** to activate
3. Give a command like "go to pricing" or ask a question

## Voice Commands

### Navigation
- "Go to features"
- "Show me pricing"
- "Take me to documentation"

### Questions
- "What is WhiteGlove?"
- "How does the AI work?"
- "Tell me about pricing"

### Actions
- "Open search"
- "Show command bar"

## Technical Details

- Uses Web Speech API for recognition
- Text-to-speech for responses
- 1.5 second silence detection
- Wake word activation for hands-free use

Try it now — click the mic and say "Hey WhiteGlove, what can you do?"
