## What You Get

### Encrypted Key Vault

Your API keys are encrypted at rest with AES-256. Keys are never logged, never exposed in responses, and can be rotated instantly without code changes.

### Unified API

One endpoint to rule them all. Send requests in OpenAI-compatible format, and we route to any provider. Switch from GPT-4 to Claude with a single parameter change.

### Real-Time Analytics

Track token usage, response latency, and costs across all providers. Get alerts when spending exceeds thresholds. Export data for your own analysis.

### Automatic Failover

If OpenAI is slow or down, we automatically route to your backup provider. Configure priority chains and never lose a request.

### Team Management

Role-based access control for your entire team. See who used what, when. Set per-user quotas and spending limits.
