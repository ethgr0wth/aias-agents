# Everything you need for adaptive UX

## Event Tracking
Automatically captures scroll, click, hover, dwell time, and exit intent signals without any configuration.

## AI Intent Engine
LLM-powered analysis infers what users want based on their behavior patterns. Works with any OpenAI-compatible API.

## Dynamic Mutations
Safe, constrained CSS and content changes that adapt your site without breaking layouts.

## Command Bar
Natural language navigation. Users tell your site what they want to see.

## Markdown Content
Define content variants in markdown. Non-technical updates, zero code deploys.

## BYOK Security
Bring your own LLM key via AiAS. Your data stays under your control.
