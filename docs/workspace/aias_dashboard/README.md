# AiAS Dashboard — AI Agents Operating System

A dark-themed, macOS-inspired dashboard for the AiAssist.net AI agents platform.

## Features

- **24 App Icons** with gradient tiles linking to real AiAssist.net endpoints
- **Drag & Drop** — click "Edit" to enter jiggle mode, drag icons to reorder (saved to localStorage)
- **Swipeable Pages** — 12 icons per page, swipe or click arrows to navigate
- **Customizable Background** — click the palette icon to choose from 8 dark themes (saved to localStorage)
- **System Overview** — live stats panel with active agents, API keys, and request counts
- **Recent Activity Feed** — real-time event log

## Getting Started

```bash
npm install
npm run dev
```

## Tech Stack

- React 19 + TypeScript
- Vite 6
- Tailwind CSS v4
- @dnd-kit (drag and drop)
- Lucide React (icons)
- Radix UI (avatar)

## Build

```bash
npm run build
npm run preview
```
